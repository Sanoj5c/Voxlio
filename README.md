# Voxlio 🎙️📚

> AI-powered platform for real-time voice conversations with your books.

## Tech Stack
- **Frontend:** Next.js 14, Tailwind CSS
- **Voice:** Vapi, ElevenLabs
- **Database:** MongoDB
- **Auth:** NextAuth.js
- **PDF:** pdf-parse

## Features
- 📄 Upload PDFs and extract text
- 🎙️ Talk to your books in real-time via voice
- 🔐 Secure authentication
- 📝 Session transcripts
- 🗣️ ElevenLabs persona previews

## Getting Started

1. Clone the repo
   \`\`\`bash
   git clone https://github.com/sanoj5c/voxlio.git
   \`\`\`

2. Install dependencies
   \`\`\`bash
   npm install
   \`\`\`

3. Set up `.env.local` with your API keys

4. Run the dev server
   \`\`\`bash
   npm run dev
   \`\`\`
